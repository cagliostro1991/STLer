## STLer 0.1.0-beta.1

First public beta. STLer puts a small picture of the model on `.stl`, `.3mf` and `.step` files in Finder instead of the generic icon. I would like people to try it on their own model folders and tell me what breaks.

### New
- Icons for STL, 3MF and STEP (`.stp`), any standard view (isometric, front, back, left, right, top, bottom), orthographic or perspective, your colour or the system one, an optional format label in a corner.
- Settings window in the style of System Settings, one page per file type, with a live preview on a bundled 3DBenchy sample (an STL, a 3MF with three plates and a STEP assembly).
- 3MF: Bambu Studio and Orca plates (show the first 1, 2, 3 or all) and a slider that blends the colours stored in the file with your fill colour.
- STEP: converted with FreeCAD or with OpenCASCADE (a 45 MB download through Homebrew, one click from the window), only one of them at a time. Optional limit for assemblies with many tiny parts.
- `stler follow` as a LaunchAgent: icons appear on their own for the folder you open in Finder, for new files, and optionally for any file you open anywhere, including a connected drive.
- A journal with a queue: Apply and Clear never block the window, you see what runs and what waits, and you can clear it.
- `stler` command line tool: `run`, `follow`, `reset`, `config`, `install`, `uninstall`, `version`, `update`.
- Update check against GitHub releases (at most once a day, can be switched off).

### Things to know
- Icons are written as custom icons, a modification date of a file is put back after that. `Clear` removes only icons STLer made.
- The build is ad-hoc signed, not notarized: right-click the app and choose Open the first time, or `xattr -dr com.apple.quarantine /Applications/STLer.app`.
- `follow` asks for permission to control Finder (it reads which folder is open).
- "Open a file anywhere" only sees places that Spotlight indexes.
- 3MF colours come from materials and from Bambu/Orca filaments per object. Per-triangle paint is not read yet. STEP colours are not read yet.

### Install
1. Download `STLer-0.1.0-beta.1-macos.zip`, unpack it.
2. Move `STLer.app` to Applications and open it. The welcome sheet explains the rest.
3. Optional: press "Set up stler follow" to keep icons up to date by itself.

Checksum: see the `.sha256` file next to the zip.
