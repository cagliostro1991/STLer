# Getting help

| You want to... | Go here |
|---|---|
| learn how it works, install, fix a common problem | the [wiki](https://github.com/cagliostro1991/STLer/wiki): Getting started, FAQ, Troubleshooting |
| ask how to do something | [Discussions, Q&A](https://github.com/cagliostro1991/STLer/discussions/new?category=q-a) |
| share an idea, show your setup | [Discussions, Ideas](https://github.com/cagliostro1991/STLer/discussions/new?category=ideas) |
| report something that is broken | [new bug report](https://github.com/cagliostro1991/STLer/issues/new?template=bug_report.yml) |
| ask for a new file format | [new format request](https://github.com/cagliostro1991/STLer/issues/new?template=format_request.yml) |
| report a vulnerability | [private report](https://github.com/cagliostro1991/STLer/security/advisories/new), see [SECURITY.md](SECURITY.md) |

In the app, General > About has "Report a problem" and "Ask or suggest" buttons that open these forms with your versions already filled in.

This is a spare-time project. Replies can take a few days. Clear, small reports with a version, the steps and (if you can share it) a small model that shows the problem get fixed fastest.
